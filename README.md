# HG 3D | Link na Bio

Página responsiva de links para a HG 3D, com identidade preta e magenta, glassmorfismo e carrossel de fotos de impressões 3D.

## Publicação
No GitHub, acesse Settings → Pages, selecione Deploy from a branch, branch `main` e pasta `/ (root)`.

## Personalização
Edite `script.js` para configurar Instagram, catálogo e conteúdo explicativo. O WhatsApp já está configurado para 94992083131.

Troque as imagens em `assets/fotos/` mantendo os nomes dos arquivos. Bootstrap 5.3.3 é carregado por CDN.
